# 🚀 Free Gamified Cybersecurity Roadmap (Zero to Expert)

A fully reworked, 100% free and gamified fork of the original [TryHackMe Roadmap](https://github.com/uttambodara/TryHackMeRoadmap). This repository retains all working, free TryHackMe rooms while seamlessly replacing every paywalled, broken, or restricted module with top-tier, interactive wargames, enterprise-grade academies, and local sandbox labs.

---

## 🛠️ The Replacement & Supplement Key
Every module that triggers a subscription wall or fails on TryHackMe has been mapped to a permanent, un-paywalled gamified alternative:
* **Linux Fundamentals (Parts 2 & 3) / System Shells** ➡️ **OverTheWire: Bandit (Levels 0–34)** (SSH command-line wargame).
* **Windows Fundamentals (Parts 2 & 3) / PowerShell Paths** ➡️ **Cmd Challenge (`cmd.fun`)** & Local Windows/WSL Administration Labs.
* **Web Security Paths / OWASP Modules** ➡️ **PortSwigger Web Security Academy** (Interactive labs with flags).
* **Binary Exploitation & Buffer Overflows** ➡️ **Pwnable.kr** & Local Kali/Ghidra reversing tracks.
* **Active Directory & Multi-Box Labs** ➡️ **Local 3-VM Home Lab (VirtualBox DC + Workstation + Kali)**.
